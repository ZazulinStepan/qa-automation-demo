QA Automation Demo

Учебный проект для демонстрации навыков в автоматизации тестирования Java-приложений.

В проекте реализованы:

- API-тесты REST endpoints
- позитивные и негативные сценарии
- параметризованные тесты JUnit 5
- unit-тесты с Mockito
- проверки данных непосредственно в PostgreSQL
- SQL JOIN
- интеграционные тесты Spring Boot
- запуск PostgreSQL через Docker Compose
- автоматический запуск тестов через GitHub Actions
